# tcr-open-data

Open data registry for TCR racing championships, drivers, calendars, and race statistics, published by **TCR Global Newsroom**.

## Format

- **One CSV file per table** (championships, seasons, events, sessions, drivers, teams, results, standings…).
- **A `datapackage.json`** at the root, following the [Frictionless Data](https://specs.frictionlessdata.io/) standard. It describes each file, its columns, their types, the keys and the licence.
- **Laps** (with sector times) are split by season, for example `laps/2027.csv`.

Only verified data, backed by an official source, is published here. The files are generated by an export from the TCR Global Newsroom platform: please do not edit them by hand, open an issue instead.
